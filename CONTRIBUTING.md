# Contributing

Bug reports, translation corrections and focused improvements are welcome.

Contributions to original project code, interface translations and documentation are accepted under the [MIT License](LICENSE).

For a bug report, please include the application version, Windows version, selected language and game server, steps to reproduce, and the expected and actual behavior. A diagnostic report exported from settings can help identify the affected runtime path. Please exclude account tokens, local profiles and other personal information from attachments.

For code changes, describe the user-visible problem and keep the change focused. Run the relevant checks in [TESTING.md](TESTING.md), inspect affected windows and include the validation results. Add a regression case when it reproduces a meaningful failure.

Please preserve desktop ownership, account isolation and local Windows time-zone behavior. New event dates should be discovered from official announcements. Do not add a manually maintained future schedule or gameplay automation.

Keep all language catalogs complete and retain grammatical forms needed by each locale. Please use English for code identifiers, message keys and developer documentation.
